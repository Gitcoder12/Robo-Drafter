# Agent Skill Map — Robo-Drafter

Use only skills relevant to the assigned issue. Each skill must produce inspectable evidence.

## Repository audit
Inspect layout, dependencies, entry points, tests and README claims. Output file paths and reproducible findings.

## Implementation
Implement one scoped feature or fix. Preserve compatibility where possible and explain trade-offs.

## Test engineering
Design deterministic tests for normal, boundary and failure behavior. Report unrun checks honestly.

## Research/evaluation
Define baseline, inputs, seeds, metrics, environment and uncertainty before claiming improvement.

## Security and data review
Check trust boundaries, secrets, file inputs, dependency risks, data provenance and privacy.

## Documentation review
Explain the user workflow simply, then add technical details, examples and limitations.

Do not autonomously merge, deploy, publish packages or access external accounts. A human maintainer owns those decisions.
